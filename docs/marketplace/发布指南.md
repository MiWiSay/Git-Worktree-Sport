# Git Worktree Sport 1.0.1：JetBrains Marketplace 发布指南

## 先说结论

`https://plugins.jetbrains.com/generator` 是 IntelliJ Platform 插件**工程生成器**，用于生成新插件骨架，不是上传入口。当前工程已经完成本地安装包、英文 Overview、图文教程和媒体素材准备；本次没有替用户登录、接受开发者协议或上传发布。

## 发布前仍需你决定的项目

1. **真实联系邮箱**：`plugin.xml` 当前只保留作者 `MiWi`，没有继续使用虚假的 `example.invalid` 邮箱。上传页面或 Vendor 信息需要你填写真实可用的联系方式。
2. **许可证/EULA**：Marketplace 要求为插件提供终端用户许可协议。免费不等于不需要选择许可证；如果选择开源许可证，还要提供公开源码链接。请按你的发布意图选择，不要直接套用默认值。
3. **兼容范围**：当前包以 Android Studio Panda 3 / platform `262.9437.185` 为目标，并在 Windows 本机完成验证。Android Studio 提供 macOS 版本，插件实现使用跨平台 API，但本版本尚未进行 macOS 实机运行验证；不要描述成所有 IDE 或操作系统均已验证。

## 手动上传步骤

1. 打开 [JetBrains Marketplace](https://plugins.jetbrains.com/) 并登录你的 JetBrains 账号。
2. 打开右上角账号菜单，选择 **Upload plugin**。这才是上传入口，不是 Generator。
3. 首次上传时选择或创建 Vendor profile，并由你本人阅读、接受 JetBrains Marketplace Developer Agreement。
4. 上传安装包：`outputs/Git Worktree Sport-1.0.1.zip`。这是插件安装包；不要上传 `发布素材.zip`、Overview 文件夹或 `Marketplace-Media` 文件夹作为插件包。
5. 填写插件详情：名称、版本、兼容产品/版本、标签、许可证/EULA、联系邮箱和支持信息。版本、插件 ID、作者和描述已经写入安装包；兼容产品仍应在发布页逐项确认。
6. 在插件详情的 **Media** 区上传 `outputs/Marketplace-Media` 中的 PNG。推荐先上传 `00-banner.png`，再按顺序上传 `01` 到 `06`。这些图已统一为 1600×1000；教程正文使用的原图在 `outputs/Overview/assets`。
7. 将 `outputs/Overview/description.html` 的内容复制到插件详情的 Overview/Description 编辑器。它是静态英语内容，适合 Marketplace 列表；不要把本地 `file:///` 路径或本机工程目录复制进去。
8. 预览 Marketplace 页面，检查产品名称、兼容版本、截图顺序、许可证、联系信息和描述，再由你本人提交审核。审核通过前不要对外宣称已经上架。

发布后的版本号必须递增。后续可以使用 Marketplace 页面手动上传，也可以在准备好账号 Token 后配置 Gradle `publishPlugin`；Token 不应写入仓库、聊天记录或文档。
