# Privacy Policy — Git Worktree Sport

**Last updated:** October 23, 2026

## 1. Overview

Git Worktree Sport is a plugin for IntelliJ Platform-based IDEs that helps users create and manage Git worktrees locally.

Your privacy is important. This policy explains how the plugin handles information when you use it.

## 2. Information Collection

Git Worktree Sport does not intentionally collect, store, or transmit personal information to the developer.

The plugin uses local repository information, such as Git worktree paths, branch names, commit identifiers, and worktree status, to provide its core functionality.

This information is processed locally on your computer and is not intentionally sent to the developer or any third party by the plugin.

## 3. Network Communications

The plugin does not require a developer-operated server or account to perform its core functionality.

Git operations are performed using the Git executable configured in your IDE. The plugin does not provide its own remote repository hosting or data synchronization service.

Any network communications initiated independently by Git, your IDE, or other installed plugins are outside the plugin's control.

## 4. Local Storage

The plugin may use the IDE's local storage mechanisms to retain plugin settings and preferences.

Such information remains on your computer unless you independently choose to share it or another application or service accesses it.

## 5. Analytics and Tracking

The plugin does not intentionally collect analytics, usage statistics, or telemetry, and does not include advertising or tracking functionality.

## 6. Third-Party Services

The plugin does not require third-party analytics services or external accounts to provide its core functionality.

The IDE, Git, and other software you use may have their own privacy policies and data-handling practices.

## 7. Data Security

Git Worktree Sport does not operate a server that receives or stores your repository information.

You are responsible for the security of your computer, local repositories, and IDE environment.

## 8. Children's Privacy

The plugin is a developer tool and is not specifically directed at children. The plugin does not intentionally collect personal information from children.

## 9. Changes to This Policy

This policy may be updated when the plugin's functionality or data-handling practices change. The latest version will be published in the project's GitHub repository.
